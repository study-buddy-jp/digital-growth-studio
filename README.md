# Digital Growth Studio website

A responsive, static business website built with HTML, CSS and JavaScript.

## Files
- `index.html` — website content
- `styles.css` — responsive design and styling
- `script.js` — mobile navigation and WhatsApp enquiry form

## Before publishing
1. Open `script.js`.
2. Replace `254700000000` with your WhatsApp number in international format, digits only. For a Kenyan number, use `254` followed by the number without the leading `0`.
3. Replace `hello@example.com` with your real business email.
4. In `index.html`, update the About text if you want to add your name and background.
5. Replace the illustrative portfolio concepts with genuine work as you complete projects. Do not present demo concepts as paid client work.

Note: The email address is currently a placeholder and is not yet connected to a form. The enquiry form opens WhatsApp.

## Preview locally
Open `index.html` in a browser. For a local development server in VS Code, open the project folder and use the Live Server extension, or run:
`python -m http.server 8000`
Then visit `http://localhost:8000`.

## Free hosting recommendation
For this static site, GitHub Pages is a suitable free starting option. It can publish the files from a GitHub repository. A custom domain is optional and usually costs money. Do not upload passwords, API keys, private customer data or payment credentials to the public repository.

## Publishing with GitHub Pages
1. Create a GitHub repository, e.g. `digital-growth-studio`.
2. Upload `index.html`, `styles.css`, `script.js`, and `README.md` to the repository root.
3. Open repository Settings → Pages.
4. Under Build and deployment, choose Deploy from a branch.
5. Select the `main` branch and `/ (root)`, then Save.
6. Wait for GitHub Pages to publish and open the generated website address shown on the Pages settings screen.

GitHub Pages documentation: https://docs.github.com/en/pages
